Hoe inloggen werkt

  • Je logt in via het officiële login.ah.nl scherm (inclusief hCaptcha indien nodig).
  • De app vangt de OAuth-code op en wisselt die automatisch in voor tokens.
  • Tokens worden opgeslagen in Docker en automatisch vernieuwd.
  • Als het popup-venster geblokkeerd wordt, gebruik het Token stappenplan.

Belangrijk

  • Dit is geen officiële AH API — gebruik op eigen risico.
  • De OpenAPI-spec kan verouderd zijn t.o.v. de live app.
